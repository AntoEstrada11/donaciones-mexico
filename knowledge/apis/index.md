# APIs

* [POST /api/auth/register](auth-register.md) - Alta de donante + partner Odoo (o mock).
* [POST /api/auth/login](auth-login.md) - Login local y emisión de token.
* [GET /api/me](me-get.md) - Perfil del donante autenticado.
* [PATCH /api/me](me-patch.md) - Actualización de perfil y sync Odoo.
* [GET /api/campaigns](campaigns-get.md) - Catálogo de campañas mock.
* [GET /api/donations](donations-get.md) - Listado mock de donaciones.
* [POST /api/donations](donations-post.md) - Crear donación pendiente (no persistida).
* [Iglesias (externa)](churches-external.md) - API WordPress IURD MX usada por el cliente.
